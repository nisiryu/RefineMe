
# 機能要件

## 1. 機能一覧
・アカウント管理
・作業管理
・課題、対策のメモ、解決状況の管理
・作業履歴の管理

## 2. 機能詳細
アカウント管理: ユーザー登録、ログイン機能
プロフィール
作業管理:　作業時間、作業概要の記録
課題、対策のメモ、解決状況の管理: 作業ごとに課題、対策、解決状況を管理
### 3. ユーザーストーリー
予定を作ってそれに沿って作業記録を残せるアプリがほしい
todoと作業記録帳の複合アプリ


## 4. 開発範囲

### MVP
ユーザー登録・ログイン・ログアウト
作業時間の計測・記録
作業内容の登録・編集・削除
作業の分類
作業に関連する課題・改善点の登録・編集・削除
課題に対する原因・対策の記録
課題の解決状況の管理
作業履歴・改善履歴の閲覧

### 追加予定機能
プロフィール
作業時間や課題の改善状況の統計・可視化
予定の登録・編集・削除
予定日時の設定
予定一覧・カレンダー表示
予定と作業記録の関連付け
予定と実際の作業時間の比較
PWA対応
